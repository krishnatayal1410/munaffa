# Munaffa — immersive homepage prototype

This branch contains the new homepage-first rebuild created after the previous product implementation was intentionally removed.

## Direction

The homepage follows a cinematic hybrid approach inspired by the five supplied motion references:

- scroll tells one continuous hospitality story rather than presenting disconnected cards;
- a persistent real-time WebGL "Munaffa Core" transforms as the story moves from guest experience to order, kitchen, recipe, inventory, settlement, leakage and profit visibility;
- cinematic full-screen hospitality imagery carries realism while WebGL is reserved for the object/data moments that benefit from real-time interaction;
- typography remains normal HTML/CSS so it stays sharp and accessible;
- reduced-motion and WebGL fallbacks are included from the start.

## Current scope

Homepage only. No dashboard, auth or backend has been reintroduced yet.
